# Yana's 9th Birthday – Pool Party Invitation

Static page (no build needed).

## Publish on GitHub Pages
1. Create a repo and upload everything in this folder (`index.html` + `assets/`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
3. Your link: `https://<username>.github.io/<repo>/`

## Set the party date
Open `index.html` and edit `PARTY_DATE` near the bottom (Philippine time, `+08:00`).
